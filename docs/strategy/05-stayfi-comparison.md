# StayFi vs Tourism Pulse

StayFi is not a competitor. It sells branded guest WiFi and email/SMS marketing to vacation-rental operators
(from ~$15/month per property): WiFi login pages capture every guest's email, integrate with PMS, screen reviews,
run a guest "HomePage" for upsells, and alert on outages and over-occupancy. It is first-party marketing tooling,
not market intelligence.

| | StayFi | Tourism Pulse |
|---|---|---|
| Unit | One property | One destination/region |
| Buyer | STR hosts, property managers | DMOs, regional governments, investors, analysts, media, developers |
| Job | Capture guests, drive direct rebooking | Explain pressure and demand outlook |
| Data | First-party WiFi/guest data | Public/official statistics + open signals |
| Moat | Installed hardware + guest lists | Transparent method + timestamped track record |

Closer comparables to Tourism Pulse: destination-intelligence vendors (Mabrian, The Data Appeal Company, Tourism Economics)
and STR market-data vendors such as AirDNA. StayFi's own blog was a secondhand source for some market statistics;
treat those as unverified.

Overlap worth noting: StayFi's guest HomePage resembles idea #9 (QR guidebook micro-SaaS) in `02-passive-income-ideas.md`.
